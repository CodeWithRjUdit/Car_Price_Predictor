# Project Structure and Runtime Flow

## Module responsibilities

- `app.py`: Streamlit entrypoint, UI controls, result display, and user-facing warnings.
- `car_price_predictor/data.py`: Loads and validates the committed cleaned dataset; removes the index column exported by the original notebook.
- `car_price_predictor/inference.py`: Loads the trusted pickle artifact and constructs the exact five-feature dataframe expected by the fitted pipeline.
- `Cleaned_Car.csv`: Reference data for valid dropdown options and observed training ranges.
- `LinearRegressionModel.pkl`: Pre-trained scikit-learn pipeline.
- `Car_Price_Predictor.ipynb`: Original exploratory data cleaning and model training workflow.
- `scripts/verify_artifacts.py`: Local smoke test for the data and model artifacts.

## Inference contract

The model receives a dataframe with columns in this exact order:

```python
["name", "company", "year", "kms_driven", "fuel_type"]
```

Do not manually one-hot encode these fields in the application. The saved pipeline already contains the fitted `OneHotEncoder` and `LinearRegression` estimator.

## Change management

When retraining the model, update the notebook or, preferably, add a reproducible training script that records the data split, preprocessing, evaluation metrics, Python version, and package versions. Replace the pickle artifact only with a model generated by that documented workflow.
